# Contributing to Vortex

Thank you for your interest in contributing to **`glastor-core/vortex`**!

## Development Standards

1. **Runtime:** Deno 2.x (`deno fmt --check`, `deno lint`, `deno task check`, `deno task test`).
2. **Zero External Dependencies:** Keep core analysis modules free of external npm/JSR dependencies to guarantee `<50ms` cold-start execution and supply-chain immunity.
3. **Contact:** [ventas@glastor.es](mailto:ventas@glastor.es) | [https://glastor.es](https://glastor.es).
